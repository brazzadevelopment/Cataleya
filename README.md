# Turnir

Mobilna web aplikacija (PWA) za nogometne turnire: raspored, rezultati uživo, tablice, ždrijeb, konačni poredak. Prvi turnir: Cataleya Cup 2026.

Uživo: https://cataleya.vercel.app/t/cataleya-cup-2026

React 18 · TypeScript · Vite · Tailwind CSS 4 · Supabase · Vercel

```bash
npm install
npm run dev     # demo način, bez baze
npm test
```
